# Cosmos DB NoSQL 0.24.0

Requires **DBX 0.6.59+**. Supported package target: **macOS ARM64 (Apple Silicon)**.

This release brings the workbench improvements since store version 0.16.0:

- **A quieter workspace:** SQL syntax errors appear once, the document panel opens on demand, and auxiliary actions share compact icon menus. Type or filter partition keys directly in the input, or use its dropdown.
- **Clearer JSON:** hierarchy guides, the active container highlight and property/item counts make nested data easier to read and fold. Formatting, copying and editing preserve large integers and decimal text.
- **Your preferred views:** result table/JSON and document fields/JSON choices are remembered independently.
- **Chinese and English:** the interface follows the DBX language. Editor search, diagnostics, confirmations and folding labels follow it too; unsupported languages fall back to English.
- **Resume per container:** SQL, partition-key text, query parameters and page size are automatically saved for each connection/endpoint/database/container. Reopening or returning restores input without running a query. Reset query is available from the menu beside the SQL heading and retains results and document edits.
- **Fewer distractions:** query parameters appear when SQL uses parameter placeholders or parameter input is populated. Existing parameterized queries remain supported.

## Upgrading and local data

Existing saved connections, selected containers, read-only settings and Account Keys remain in place. No new host permissions or MCP tools are added. MCP stays read-only; UI writes retain confirmation and ETag safeguards.

**Query input is now saved locally as plaintext**, including SQL literals and parameter values, in private `query-input-v1` files (0700 directories / 0600 files on Unix-like systems). It is isolated by connection and container, not synchronized, and not exposed through MCP. Reset query replaces the saved input for the current scope with defaults. Query results, unsaved document bodies and undo history are not persisted; a forced exit can lose an in-flight save. See [runtime behavior and data access](https://github.com/fwrq41251/dbx-plugin-cosmosdb/blob/v0.24.0/docs/SECURITY.md).

Account Key authentication and the existing cross-partition query pipeline limitations remain unchanged. Query history/favorites and automatic recovery of unsaved document edits are outside this release.

## Installation and validation

The GitHub Release workflow produces an **unsigned review candidate**. Ordinary users should install the signed package from DBX Marketplace after the store update is reviewed, signed and merged.

Validation: 49 frontend tests, 66 Go race tests, Go vet and 78 browser tests passed. The macOS ARM64 package passed SHA-256, file checksum, license, protocol v1 and connection-lifecycle checks. Native DBX installation and close/reopen input restoration were verified without executing business queries or modifying business documents. Documentation screenshots use local mock data only.
