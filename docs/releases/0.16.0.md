# Cosmos DB NoSQL 0.16.0

Requires **DBX 0.6.59 or later**. Supported store target: **macOS ARM64**.

This update brings the improvements since store version 0.8.0:

- Read-only MCP tools for container metadata, explicit-partition SQL queries, document point reads and cached partition-key lookup, compatible with DBX 0.6.59 and MCP Server 0.4.134.
- Searchable database/container breadcrumbs. The plugin remembers the last validated selection for each connection; reopening the workbench and subsequent MCP calls use that location.
- Selected-SQL execution, inline syntax error locations, query cancellation, elapsed time and clearer RU/result status.
- Result tables with all returned fields, remembered column widths, local page filtering, keyboard navigation and precise cell/row copying.
- A searchable, foldable JSON result viewer with per-item copy and full-document actions, plus a more compact workbench and clearer document change markers.

## Upgrading

1. Upgrade DBX to 0.6.59+ before installing this version.
2. Existing database/container defaults migrate automatically on successful connection. These fields no longer appear in the connection form; select the location in the workbench instead. Failed location saves retain the current container and document draft.
3. For MCP, enable Cosmos DB NoSQL under Settings → MCP → Capabilities with the **Read only** ceiling, and permit the intended connections under Permission management. Use MCP Server 0.4.134 and restart the client's MCP server after changing its configuration.

MCP always remains read-only even for writable UI connections. Changing the selected location invalidates old MCP pagination cursors. UI writes retain their confirmation, read-only and ETag protections. Query cancellation does not refund consumed RU.

The GitHub Release contains an **unsigned review candidate**. The DBX Store update becomes available after maintainer signing and merge; ordinary users should install the signed store package. Account Key authentication and existing cross-partition query limitations remain unchanged. Query history/favorites are not included.

Validation: 31 model tests, 60 Go race tests, Go vet and 61 browser tests passed, with native package integrity/protocol checks and read-only live MCP checks across four configured Cosmos environments. Test data and screenshots contain no private connection credentials or business documents.
