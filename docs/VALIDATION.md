## 本机 DBX 与真实 dev 验证（已安装版本 0.4.0）

- 在已安装的 DBX 0.6.49 中更新 `io.local.cosmosdb` 至 0.4.0，界面显示 Compatible。
- 使用真实 Azure 开发账号的现有只读 Key 验证连接；插件和 DBX 连接均设置为只读。账号标识、密钥与业务数据不随源码分发。
- 数据库列表与容器列表加载成功。
- 连接已配置到容器层，关闭连接再重开后自动恢复指定数据库和容器，并保持只读。
- 在指定逻辑分区上执行 `SELECT TOP 10 c.id, c._ts FROM c` 类型的投影查询，成功返回 10 条记录。
- 按 id 和分区键读取完整文档成功。只读状态下新增、保存和删除按钮保持禁用。
- 未指定分区键的跨分区 TOP 查询实际返回 HTTP 400，服务提示需要客户端处理查询管线。该限制已确认存在，当前不能声称完整跨分区 SQL 支持。

- 0.4.0 索引跳读小规模验证：连续 3 个不同字符串分区键，每次 2.82 RU，总计 8.46 RU；仅输出统计，不记录业务键值或凭据。
- 同一 dev 容器完整发现对比：0.3.0 DISTINCT 返回 419 个键、62702.58 RU；0.4.0 索引跳读返回同样 419 个键、1224.61 RU，RU 下降约 98.05%。这是当前容器的实测，不代表所有容器的固定开销。
- 关闭 dev 连接再重开，分区键列表从本地缓存恢复 419 个键，界面显示本次 0.00 RU 与缓存时间；此数值仅指分区键发现，不包含连接验证和容器元数据读取。
